## 💼 Featured Projects

### 🎮 [Isolation Game Bot - Adaptive Minimax AI](https://github.com/Msindisi-Carlet101/isolation-game-cpp)
**C++ | Game Theory | AI Algorithms**

An intelligent bot achieving **92% win rate** through position-independent evaluation and adaptive search depth.

**Key Features:**
- Minimax search with alpha-beta pruning (75% node reduction)
- Multi-layered mobility analysis for trap detection
- Adaptive depth control (3-6 ply) based on game phase
- Beam search optimization (12 candidates per level)

**Technologies:** C++17, Code::Blocks, Advanced heuristics

**Results:** 92% win rate (random positions), 100% win rate (fixed positions) over 125 games

---

### 🔐 [Access Control System - AVR Assembly](https://github.com/Msindisi-Carlet101/access-control-avr)
**AVR Assembly | ATmega328P | Embedded Systems**

A secure, interrupt-driven access control system demonstrating professional embedded design principles.

**Key Features:**
- 100% interrupt-driven architecture (zero polling)
- Hardware PWM servo control via Timer1
- 4-digit keypad authentication with code programming
- Progressive security (Error → Alarm states)
- 7-segment display for real-time feedback

**Technologies:** AVR Assembly, Timer1 (Fast PWM), Timer2 (CTC), PCINT

**Highlights:** Sub-5ms response time, precise 3-second auto-lock, stable state machine

---

### 🔬 [Crypto-Box - Flex Sensor Subsystem](https://github.com/Msindisi-Carlet101/crypto-box)
**Analog Circuit Design | Signal Processing**

Designed flex sensor input subsystem with Wheatstone bridge and instrumentation amplifier.

**Key Components:**
- SEN-10264 flex sensor integration
- Wheatstone bridge for precision measurement
- Instrumentation amplifier with comparator ladder
- LED array visual feedback system
